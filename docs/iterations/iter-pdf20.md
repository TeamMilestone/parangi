# Iteration pdf20: E2E 테스트 (500개 PDF, Java PDFBox 비교)

## 테스트 방법

### 데이터
- superboard의 20,219개 PDF 중 500개 랜덤 샘플 선택
- Rust: `pdfbox-text-cli` 배치 모드로 추출
- Java: 기존 `superboard/data/raw/text/` 결과 활용

### 비교 메트릭
- **문자 빈도 유사도** (cosine similarity): 같은 문자들이 출력되는지
- **라인 집합 유사도** (Jaccard): 동일 줄이 존재하는지
- **길이 비율**: 출력 길이 비율
